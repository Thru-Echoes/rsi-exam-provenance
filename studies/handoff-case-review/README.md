## Reproduce
From repository root:
```sh
python3 studies/handoff-case-review/review_cases.py --check
# Optional: compare projections against the pinned original files:
python3 studies/handoff-case-review/review_cases.py --check --proofpress-root /path/to/proofpress
```
The optional source checkout must contain the recorded source bytes. The portable check uses the included projection and verifies retained sources; source authenticity still relies on the stated origin, not a signature.
